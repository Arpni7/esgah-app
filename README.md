# إصغاء (Esgha) — مرافقك الشرعي بالذكاء الاصطناعي

مشروع لتحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي — المسار: **الحوار المعرفي والإجابات الموثوقة**.

## الفكرة
منصة ويب بوضعين مترابطين:
- **استمع:** التقاط خطبة/درس بالميكروفون أو رفع ملف (صوت/فيديو/صورة)، ثم تفريغ وترجمة فورية وملخص حي، مع استخراج الآيات والأحاديث المذكورة فعلاً.
- **استفتِ:** حوار فقهي مبني على قاعدة معرفة موثقة، يعرض الأدلة وآراء المذاهب أو فتوى الشيخ مع رابط المصدر، ومعه أدوات: متابعة النقاش، محاكاة شبهة، تبسيط (لطفل / لغير مسلم جديد)، وخطة تطبيق عملية.

## دور الذكاء الاصطناعي
- تحويل الكلام لنص وفهم الوسائط (Gemini متعدد الوسائط)
- ترجمة وتلخيص توليدي
- مطابقة دلالية للسؤال مع قاعدة المعرفة (RAG مبسّط)
- حوار متعدد الأدوار مقيّد بمعطيات المسألة الموثقة

## البنية
```
public/index.html   الواجهة
api/ask.js          مطابقة السؤال بقاعدة المعرفة
api/assist.js       متابعة النقاش / محاكي الشبهات / التبسيط / الخطة العملية
api/listen.js       ترجمة وتلخيص واستخراج الآيات والأحاديث من النص
api/transcribe.js   تحليل ملف صوت/فيديو/صورة
data/dataset.json   قاعدة المعرفة (18 مسألة)
```

## التشغيل محلياً
1. ثبّت Node.js و Vercel CLI: `npm install -g vercel`
2. أنشئ مفتاح Gemini من https://aistudio.google.com
3. `vercel env add GEMINI_API_KEY` (اختر Development ثم الصق المفتاح)
4. `vercel dev` ثم افتح http://localhost:3000 في Chrome

> ملاحظة: `vercel dev` يقرأ المتغيرات من إعدادات Vercel، وليس من ملف `.env` المحلي.

## النشر
`vercel --prod` (بعد إضافة `GEMINI_API_KEY` في Production).

## الأمان
لا تُرفع أي مفاتيح أو أسرار. المفتاح يُقرأ من متغير البيئة داخل دوال السيرفر فقط، وملف `.env` مستثنى في `.gitignore`.

## حدود معروفة
- قاعدة المعرفة تجريبية (18 مسألة)، والنظام يقرّ بأن المسألة غير متوفرة بدل اختلاق إجابة.
- رفع الملفات محدود بحوالي 4 ميجا (حد منصة الاستضافة).
- الخطة المجانية لـ Gemini لها حدود طلبات قد توقف الخدمة مؤقتاً.
- المحتوى لا يغني عن مراجعة أهل العلم.
